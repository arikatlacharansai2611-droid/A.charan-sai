# ⚡ TaskFlow — Task Management Application

A full-featured task management web app built with pure HTML, CSS & JavaScript.
**Built by A. Charan Sai** · B.Tech CSE (AI & ML) · ALIET, Vijayawada

## 🌐 Live Demo
> https://arikatlacharansai2611-droid.github.io/taskflow

## ✨ Key Features
- ✅ **User Authentication** — Login & Register (localStorage)
- ✅ **CRUD Operations** — Create, Edit, Delete tasks
- ✅ **Kanban Board** — 3-column drag-ready board (To Do / In Progress / Done)
- ✅ **List View** — Table view with all tasks
- ✅ **Priority System** — High / Medium / Low with color indicators
- ✅ **Search & Filter** — Real-time search + priority filter
- ✅ **Activity Log** — Track all task changes
- ✅ **Responsive Design** — Works on mobile & desktop
- ✅ **Real-time Stats** — Live task counts & progress bar
- ✅ **No Backend** — 100% client-side, localStorage powered

## 🛠 Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Plus Jakarta Sans, JetBrains Mono)
- localStorage for data persistence
- Zero dependencies — no npm, no framework

## 🚀 Deploy on GitHub Pages (FREE — 2 minutes)

### Step 1: Create Repo
1. Go to github.com → New repository
2. Name it `taskflow` (or any name)
3. Set to **Public**
4. Click **Create repository**

### Step 2: Upload File
1. Click **"uploading an existing file"**
2. Drag `index.html` into the box
3. Click **Commit changes**

### Step 3: Enable Pages
1. Go to repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** → **/ (root)**
4. Click **Save**
5. Wait 1-2 minutes → your site is LIVE! 🎉

### Your URL will be:
`https://YOUR-USERNAME.github.io/taskflow`
